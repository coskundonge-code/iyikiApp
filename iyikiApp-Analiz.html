🎁 5. Hediye Yaşam Döngüsü (Gift Lifecycle)

Bir hediyenin gönderilmesinden kullanılmasına veya askıda havuzuna düşmesine kadar geçen süreç:

stateDiagram-v2
    [*] --> PENDING: Hediye gönderildi
    PENDING --> CLAIMED: Alıcı QR ile kullandı
    PENDING --> EXPIRED: Süre doldu (72 saat)
    EXPIRED --> SOCIAL_POOL: Askıda havuzuna aktarıldı
    SOCIAL_POOL --> DISTRIBUTED: Havuzdan birine dağıtıldı
    PENDING --> CANCELLED: Gönderici iptal etti
    CLAIMED --> [*]: Tamamlandı
    DISTRIBUTED --> [*]: Tamamlandı
    CANCELLED --> [*]: Sonlandırıldı

    note right of PENDING
        Gönderici: dailySendCount++
        Alıcıya SMS/Push bildirim
        redeemCode üretildi
    end note

    note right of CLAIMED
        Branch seçildi
        QR doğrulandı
        iyikiScore++
    end note

    note left of SOCIAL_POOL
        "Askıda Kahve" modeli
        Topluluk havuzuna düşer

    end note

🔍 7. Mevcut Durum Analizi

Güçlü Yanlar

  • Konsept "Fiyatsız hediye" fikri özgün ve duygusal bağ kuruyor. Türkiye'de benzeri yok.
  • Mimari Next.js 16 App Router + Supabase: modern, hızlı geliştirme altyapısı.
  • Veri Modeli 12 tablo ile kapsamlı bir şema: fraud koruma, askıda havuzu, planlı gönderim, analytics var.
  • Rol Sistemi 4 farklı panel (User, Admin, Partner, Sponsor) ile çok taraflı platform mimarisi hazır.
  • Fallback Supabase erişilemezse mock data'ya düşen resilient bir yapı var.
  • UX Framer Motion ile akıcı animasyonlar, mobile-first tasarım.

Zayıf Yanlar & Eksiklikler

  • Auth Gerçek Supabase Auth entegrasyonu eksik — login fonksiyonu kullanıcıyı DB'den bulup direkt giriş yapıyor, OTP doğrulaması yok.
  • API Katmanı Hiçbir API route yok — tüm veritabanı işlemleri client-side'dan yapılıyor. Bu ciddi bir güvenlik açığı.
  • RPC decrement_gift_stock ve increment_user_score RPC fonksiyonları çağrılıyor ama SQL tanımları yok.
  • Validasyon Form validasyonu ve input sanitization eksik. Zod veya benzeri bir kütüphane kullanılmıyor.
  • Test Hiçbir test dosyası yok — ne unit ne integration ne e2e.
  • Error Handling Tüm catch blokları boş veya sadece fallback'e düşüyor. Kullanıcıya hata mesajı gösterilmiyor.
  • i18n Türkçe hardcoded — çoklu dil desteği yok.
  • Accessibility ARIA etiketleri ve keyboard navigation eksik.
  • Expire Cron Süresi dolan hediyeleri otomatik EXPIRED yapan bir cron/edge function yok.
  • PWA Service worker ve manifest.json yok — offline çalışma ve ana ekrana ekleme desteklenmiyor.

Faz Detayları

🔴 Faz 1 — Temel Güvenlik & Altyapı (Nisan 2026, Hafta 1-3)

Hedef: Uygulamayı production-ready güvenlik seviyesine getirmek.

  • API Routes: Tüm veritabanı işlemlerini server-side'a taşı. Client'tan direkt Supabase erişimini kaldır.
  • Gerçek Auth: Supabase Phone Auth ile OTP doğrulamasını aktif et. Session yönetimini düzgün kur.
  • Validation: Zod ile tüm form ve API inputlarını doğrula. XSS ve injection koruması.
  • RPC: decrement_gift_stock ve increment_user_score SQL fonksiyonlarını yaz + atomic transaction garantisi.
  • Error Handling: Boş catch bloklarını kullanıcı dostu hata mesajlarıyla değiştir. Sentry veya benzeri monitoring ekle.

🟠 Faz 2 — Core İşlevsellik (Nisan-Mayıs 2026)

Hedef: Hediye yaşam döngüsünü tam otomatize etmek.

  • Expire Cron: Supabase Edge Function veya pg_cron ile süresi dolan hediyeleri otomatik EXPIRED yap.
  • Askıda Havuzu: EXPIRED → SOCIAL_POOL → DISTRIBUTED geçişlerinin otomatik dağıtım algoritması.
  • Push Notification: Firebase Cloud Messaging veya OneSignal ile gerçek zamanlı bildirimler.
  • SMS: Netgsm veya Twilio ile hediye bildirim SMS'leri.
  • Partner Webhook: Hediye kullanıldığında partner'a otomatik callback.

🟡 Faz 3 — Test & Kalite Güvencesi (Mayıs 2026)

Hedef: Güvenilir, regresyon-free bir geliştirme süreci.

  • Vitest: Store, queries, mappers için unit testler.
  • Integration: API route testleri, Supabase mock ile.
  • E2E: Playwright ile kritik kullanıcı akışları (login → send → redeem).
  • CI/CD: GitHub Actions ile otomatik test, lint, build, deploy.

🟢 Faz 4 — Kullanıcı Deneyimi & Yeni Özellikler (Mayıs-Haziran 2026)

Hedef: Retention artıran gamification ve topluluk özellikleri.

  • Haftalık Drop: Sınırlı sayıda hediye, first-come-first-served mekanizması.
  • Başarımlar: Jest Ustası, Askıda Kahraman gibi rozetler ile motivasyon.
  • Topluluk Havuzu: Üniversite, mahalle, iş yeri bazlı hediye paylaşım grupları.
  • 1+1 İkram: Sponsor destekli "bir al bir hediye et" modeli.
  • PWA: Offline desteği, ana ekrana ekleme, push notification.

🔵 Faz 5 — Büyüme & Ölçeklendirme (Haziran-Temmuz 2026)

Hedef: İş ortaklarını güçlendirmek ve veri odaklı kararlar almak.

  • Analytics Dashboard: Gerçek zamanlı KPI'lar: DAU, hediye/gün, dönüşüm oranı.
  • Partner Self-Service: Partner'ların kendi ürünlerini, stokunu, şubelerini yönettiği portal.
  • Sponsor Kampanya Builder: Sponsor'ların kampanya oluşturup sonuçlarını takip ettiği araç.
  • Performance: React Server Components, lazy loading, image optimization.
  • Accessibility: WCAG 2.1 AA uyumluluğu.
